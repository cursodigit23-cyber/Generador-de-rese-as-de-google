Enlace de reseñas de Google

Ingresa tu Place ID o pega un enlace de Google Maps.

Paso 1: Consigue tu Place ID con la herramienta oficial de Google

  1. Abre esta URL en una nueva pestaña: https://developers.google.com/maps/documentation/javascript/examples/places-placeid-finder
  2. En el campo de búsqueda, escribe el nombre exacto de tu negocio.
  3. Selecciona tu negocio de la lista de resultados.
  4. El Place ID aparece automáticamente en un recuadro debajo del mapa. Ejemplo: ChIJ3zZGNQpFYA0R4hVJZZqqooY
  5. Copia ese código (selecciónalo y pulsa Ctrl+C).

Paso 2: Usa esta herramienta para generar tu enlace de reseñas

  1. Vuelve a esta página.
  2. Pega el Place ID que copiaste en el campo que dice “Pega el Place ID del negocio”.
  3. Haz clic en “Generar enlace a reseñas”.
  4. ¡Listo! Verás aparecer:
    • Un enlace de texto que puedes copiar y pegar donde quieras (WhatsApp, email o redes sociales).
    • Un código QR que puedes copiar o descargar como JPG para imprimir en flyers, tarjetas o mostradores.

Este ID se detectó leyendo la página del negocio, no la URL. Confirma con “Probar enlace” que sea el correcto.

Pulsa “Probar enlace” para confirmar que abre el negocio correcto.
